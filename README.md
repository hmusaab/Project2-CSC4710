How to configure, run, install:
1) using git clone the repo via github (from iffatR-Branch(main)) or download the source code from this folder:
https://github.com/hmusaab/Project2-CSC4710/tree/iffatR-branch

2) Make sure to have XAMPP control panel installed. Hit start for Apache and MySQL. Also hit Admin for MySQL.
Go ahead and look at the .env file to see what the name of the database should be and create a new database per name. Use the sql.txt file to create the tables in the database.

3) in the terminal, type the path in which the project directory is stored on your local machine. cd in to the backend directory and type npm start. Open the index.html page and continue as you see fit.
